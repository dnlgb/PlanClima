## PlanClima

Una aplicación web que recomienda actividades según el clima de una ciudad.

## Funcionalidades

- Buscar ciudades.
- Consultar el clima actual usando Open-Meteo.
- Elegir una actividad.
- Calcular un score según las condiciones climáticas.
- Mostrar una recomendación basada en ese score.

---

## Tecnologías

- HTML
- CSS
- JavaScript
- Open-Meteo Geocoding API
- Open-Meteo Forecast API

---

## Lo que practiqué

Con este proyecto practiqué cosas que tenia por reforzar

- Fetch API
- Promesas
- Eventos
- Consumo de APIs
- Lógica de negocio usando un sistema de score

También aprendí a organizar un proyecto un poco más grande de lo que había hecho hasta ahora.
